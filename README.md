# StudyAI – AI Student Companion

A fully responsive, client-side web app designed for students. All data is saved locally in the browser (no account needed).

## Features

- **AI Chat** – Ask questions, get explanations, quizzes, study tips
- **Speech-to-Text Notes** – Dictate notes using your browser’s Web Speech API
- **Note Taking & Organizer** – Create, edit, tag by subject, and store notes locally
- **Class Schedule** – Track your classes (day, time, location)
- **Club Schedule** – Same for clubs and extracurriculars
- **AI Homework Helper** – Step-by-step guidance for assignments
- **AI Schedule Planner** – Generate a study plan based on your goals and available time
- **Dark / Light mode**
- **Fully responsive** (mobile + desktop)

## How to use

1. Open `index.html` in any modern browser (Chrome/Edge recommended for best speech-to-text support)
2. Or deploy it (GitHub Pages, Vercel, Netlify, etc.)

## Tech

- Pure HTML + Tailwind CSS (CDN) + Vanilla JavaScript
- `localStorage` for persistence
- Web Speech API for speech-to-text

No backend required. Ready to be extended with a real AI API later.

---

Made for students who want a simple, private, offline-capable study companion.
